# znbu

Canonical design and backlog for Matomeru, with related product ideas kept in a separate ecosystem section. Product implementation lives in Matomeru; documentation tooling lives here.

- [Outline](docs/outline.md): concept index, current behavior and explicitly labeled target designs.
- [Todo](docs/todo.md): remaining acceptance criteria, unfinished plans and verification-pending work.
- [Inventory](docs/outline/inventory.md): first-class category for interconnected tracked things; ownership versus reuse and remaining design decisions.
- [Source coverage](docs/sources/README.md): preserved originals and their canonical destinations.
- [Maintenance](docs/maintenance.md): where changes belong, promotion rules and documentation checks.
- [Prompt archive](docs/prompts/README.md): historical instructions, not a second backlog.
- [clean-mtm](~/hub/prompts/clean-mtm.md): historical instructions, not a second backlog.

Edit the concept documents, not the historical snapshots. An outline proposal is not proof of implementation; its status and linked todo define what remains.
