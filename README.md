# znbu

Home of the prompt and the docs that generate the ideal deck: a terminal dashboard over the tuios daemon.

- `docs/outline.md`: the spec, nested lists, shapes and relationships. Its git history is the history of the design.
- `docs/prompts/`: every prompt given to an agent that built from the outline, indexed with when, to whom and whether it steered a running turn.

No code lives here. Builds happen in other repos from this outline.
